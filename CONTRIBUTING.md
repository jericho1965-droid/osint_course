Guida al Contributo - Corso OSINT Pratico

Grazie per l'interesse nel contribuire a questo corso! Il contributo della community è fondamentale per mantenere aggiornati i contenuti, gli script e i riferimenti normativi.

Come Contribuire

1. Segnalazione di Bug o Inesattezze

Se riscontri un problema negli script Python o un errore nei testi didattici:

Controlla nella sezione Issues che il problema non sia già stato segnalato.

Apri una nuova Issue descrivendo dettagliatamente il problema, l'ambiente di esecuzione (es. OS, versione di Python) ed eventuali messaggi di errore.

2. Proporre Modifiche o Nuovi Moduli

Effettua il Fork del repository.

Crea un branch dedicato per la tua funzionalità o correzione:

git checkout -b feature/nome-funzionalita


Assicurati che gli script Python rispettino le convenzioni PEP 8 e siano ben documentati.

Esegui i test/check automatici prima di effettuare la commit.

Invia una Pull Request (PR) spiegando le modifiche apportate.

Convenzioni di Codice e Stile

Python: Utilizza la sintassi standard di Python 3.8+.

Lingua: Tutta la documentazione principale e i commenti del codice devono essere in lingua italiana.

Legge & Etica: Non inserire strumenti o esempi che promuovano l'uso illegale o non autorizzato dell'OSINT.
